# Findings

All Q entries below are **CONFIRMED**, high confidence, from baseline
`809e3ab` or explicitly identified intermediate corrections. P1 means high
security/data-integrity impact; P2 means a material reliability or workflow
failure. Passing original tests did not disprove the reproductions.

| ID / priority | Contract, affected path and reproduction | Observed vs expected / user impact | Correction, tradeoff and verification |

[Evidence](evidence/product/baseline-product.jsonl) | All commands succeed, but IDs collide; repeated identical briefs overwrite tasks (13 persisted in retained trial; 14 in initial exploratory trial). Expected 20 separately addressable tasks. | Serialize allocation across processes, reserve incomplete-directory IDs, refuse existing directory creation.
