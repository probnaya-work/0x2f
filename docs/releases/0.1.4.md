# 0x2F 0.1.4

- Task creation prints the persisted Task ID and its exact `2f open <id>`
  command. Reopen Tasks from another process and inspect individual runs;
  incomplete `--run` selections now report a usage error.
- Continue the same Task through another harness with
  `2f rerun <id> --provider <provider>`. Prior results, decisions, and evidence
  remain available through persisted Task context. One real Codex → OpenCode
  engineering correction has been verified without a manual handoff.
- OpenCode is built in through the existing ACP integration (`opencode acp`);
  an installed OpenCode CLI and an available, configured model are required.
- Set `CODEX_IGNORE_USER_CONFIG=1` to use Codex's account default instead of
  unsupported user-config overrides. Existing authentication is preserved;
  ordinary Codex configuration remains unchanged unless this option is set.

CLI, TUI, and Web continue to use the same durable Task state. This release
does not include the experimental managed Responses lane or change scheduler,
credentials, or unattended-execution policy.

The continuity observation concerns a new run on the same Task through a new
harness session; it does not imply resuming the original provider session.
